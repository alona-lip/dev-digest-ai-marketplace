# hello-world

Example plugin for `dev-digest-ai-marketplace`. It exists to verify that the marketplace can be added, the plugin can be installed, and its skill loads.

## Install

```
/plugin install hello-world@dev-digest-ai-marketplace
```

## Components

| Component | Invocation | What it does |
| --- | --- | --- |
| Skill `hello` | `/hello-world:hello [text]` | Confirms the plugin is loaded and echoes any arguments |

## Dependencies

None.
