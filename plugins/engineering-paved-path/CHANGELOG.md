## [1.0.0] - 2026-10-30

### Added

- Eleven stack skills: `react-best-practices`, `next-best-practices`, `react-testing-library`, `frontend-architecture`, `fastify-best-practices`, `drizzle-orm-patterns`, `postgresql-table-design`, `onion-architecture`, `zod`, `typescript-expert`, `security`.
- `onion-architecture` 2.0.0: rings defined by role for any Fastify + Zod + Drizzle backend, with a dependency-cruiser rules template that has path placeholders and optional rules for a pure package.
- `frontend-architecture` 1.1.0: §10 tells the agent to read the project's `CLAUDE.md` / `AGENTS.md` for overrides instead of describing one product's frontend.
- Skill evals for `frontend-architecture` and `onion-architecture`, set in neutral sample apps.
